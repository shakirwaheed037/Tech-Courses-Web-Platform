📘 About

A full-stack Tech Courses Web Platform built using Node.js, Express, MongoDB, and vanilla JavaScript. The platform allows users to explore and enroll in courses, while providing admins with tools to manage course content efficiently.
It includes secure user authentication, role-based access control (Admin and Student), and dynamic course management features. The system also supports image uploads for courses, making the platform more interactive and visually engaging.

🚀 Key Features

User Authentication (Login / Register)
Role-Based Access (Admin / Student)
Course Management (Add, Update, Delete)
Image Upload Functionality
RESTful API Architecture
Responsive Frontend (Vanilla JS)
🔐 Environment Variables (.env)

Create a .env file in the root directory and add the following:

PORT= write a port number like 5000
MONGODB_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key

⚠️ Important Notes

Do not upload your .env file to GitHub
Always add .env to your .gitignore
Replace values with your own secure credentials

📌 Project Goal
This project is designed to simulate a real-world e-learning platform and demonstrate full-stack development skills, including backend API development, authentication systems, and database integration.
